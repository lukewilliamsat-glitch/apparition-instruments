## Network evidence

Kernel filter blocks socket creation/connect/datagram-message sends/io_uring and persists into child processes. Harmless direct IPv4/IPv6 probes use documentation IP ranges; loopback also denied. DNS uses `.invalid`, no production target. Direct child TCP gets EPERM, fetch/WebSocket stubs refuse, `/proc/self/status` confirms Seccomp 2 and NoNewPrivs 1. Logs are in network-probes.stdout.txt. This is kernel process/child isolation, not browser request interception. No browser was launched.
