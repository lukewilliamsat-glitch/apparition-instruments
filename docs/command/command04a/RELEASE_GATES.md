# NOCTURNE release gates

Automated isolated acceptance and owner design approval are separate gates. This candidate is not installed in production.

1. **Owner visual approval remains open.** Review the original before/after captures, especially charcoal/brass balance, desktop information density, supporting-text size, phone section chooser, catalogue shortcut and fixed phone action tray.
2. **Accessibility scope is bounded.** Functional Chrome checks cover keyboard tabs, labels/instructions, invalid-field navigation, focus visibility/restoration, Escape, reduced motion, increased text and action hit testing. No screen-reader, comprehensive WCAG, cross-browser, real-device touch or on-screen-keyboard certification is claimed.
3. **Backend integration remains unverified.** The inherited IRONCLAD model and SQL are unchanged. The original 61/61 disposable PostgreSQL result remains historical evidence; no SQL was executed in this presentation mission. Actual Supabase authentication, schema/grants/RLS, all legacy writers, revisions, inventory/private-cost authority, audit/receipt retention and production operation IDs require their separate review.
4. **Publication remains separately gated.** No main integration, production workflow change, complete publication payload, rollback certification, hosting change or deployment is authorised by this candidate. NIGHTFALL/HOMECOMING and other frozen workstreams remain unchanged.
5. **Screenshot retention is temporary.** Authorisation 41 permits original PNG retention in the verified Actions artifact only. The screenshots are not committed to public Git. Artifact expiry does not preserve image bytes; the Git manifests preserve provenance, not a replacement for the images.

After owner design review and confirmed backend restoration, the recommended next separately authorised engineering mission is a bounded read-only backend compatibility/security/legacy-writer assessment. Specify service roles, exact requests, projections, byte ceilings, sensitive-output handling and stop conditions before execution.
