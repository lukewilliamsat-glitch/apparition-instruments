# Discovery V3: additive published knowledge journeys

Thirty CMS publications drive the public knowledge graph. Fourteen existing primary intent nominations and query families remain unchanged; eight supporting guides extend relevant families rather than claiming a second primary page. Search Console evidence is not an input and no verification token is invented.

The CMS generator stages its complete output before touching routes. Its additive discovery adapter supplies eight searchable cards, category reading-list additions, three start-here journeys, tool-to-guide reference panels and `knowledge.json`. Titles, paths, introductions and associations come only from public immutable snapshots. No draft API is used. Marker-delimited additions permit deterministic preservation checks against the accepted Hub and three tools. The existing Hub search and signal controllers, markup, reveal behaviour and styles are preserved. Original article presentations are unchanged.

Tool links use existing canonical entry routes, without invented state queries. Educational coverage does not imply a modification is supported by a particular tool. Tool equations, terminal authorities, configuration logic and commercial hand-offs are untouched.

Do not run the legacy pre-CMS Hub generator to publish newer CMS content. `scripts/generate-hub-cms.mjs` is the current publication authority and regenerates additive discovery from published records. New private drafts do not appear in the graph or crawlable navigation.
