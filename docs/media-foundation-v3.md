# Private media foundation and Admin coherence

`dist/authoring/media.mjs` defines generic asset and usage validation without importing Apparition, database, commerce or electrical modules. Asset identity, file/type, dimensions, size, hash and an adapter-approved reference are separate from article/block usage, alt text, caption and decorative intent. The generic document metrics implementation now lives beside generic document primitives; the accepted CMS adapter re-exports it without changing callers.

The Apparition adapter uses a private approved-static-asset registry, seeded with the existing logo's verified PNG metadata and SHA-256. It creates no bucket, uploads no file and changes no image. Authenticated Admins may read the registry and save private article associations with a future block-reference field. Both tables use RLS with authoritative membership checks. Direct client mutation is revoked. The security-definer save RPC has an empty search path, explicit grants, membership enforcement, foreign keys, bounded text and optimistic concurrency. Locking the article serialises first inserts without updating the article. Revoked membership stops access immediately. No public RPC exposes media associations.

Media metadata is a **private planning sidecar**, not yet part of article revision content. Saving it never changes CMS edit versions, published pointers, renderer input or an article's public presentation. Future image insertion must define a sanitised immutable media projection inside the article publication contract first. Arbitrary uploads, SVG ingestion, remote assets, public image blocks and revision-bound media publication are deferred. Existing public images remain under their accepted rendering authorities. A future upload adapter must verify decoded content/type/dimensions, use constrained storage policies and publish only sanitised approved references.

A compact, collapsed workspace switcher is added to Inventory/Products, Orders, Wiring Kit Master, Catalogue Settings, Articles, Media and Site Operations. It links to existing News, Announcements and commercial configuration panels using their actual anchors. Existing navigation, gate, controls and controllers remain byte-for-byte preserved outside marked additions. A separate opt-in stylesheet affects only `.admin-page .admin-workspaces`; no global token is changed.
