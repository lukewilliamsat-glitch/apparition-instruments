| Dependency / decision | What may be established | What still requires separate authority |
|---|---|---|
| Provider recovery — A | Dated owner-confirmed actual cycle, allowance and project/enforcement state | No public endpoint test; A remains ON HOLD until the report is supplied under its own scope. |
| Egress safety | Owner baseline/reserve plus explicit acceptance of schedule, visitors and reporting uncertainty | Any workflow/control change; no claimed billed-egress ceiling from response caps. |
| NIGHTFALL public compatibility — B | Exact three-request sampled public contract after approval of preserved plan/transport | No schema repair, view creation, image download, wider inventory, retry or security certification. |
| Privileged COMMAND compatibility — C, separately | Exact reviewed metadata contracts and approved trusted channel; reconcile deployed JWT/membership, grants/RLS, shared revision, idempotency and all writers | No real mutation, SQL/RLS change, fixture trust-auth adoption or automatic C after B. IRONCLAD fixture success does not prove deployed Supabase integration. |
| Image/publication infrastructure | Approved real identity/inventory/capture, authentic immutable archive, lifecycle/bootstrap policy, hosting/cache/DNS/TLS choices | Dedicated least-privilege infrastructure and physical-device acceptance; no image retrieval/publication or NIGHTFALL activation in this mission. |
| Complete release payload and rollback | Exact active payload provenance, full per-file inventory/hashes, complete retained prior payload, independently verified restoration and publication-only route | Missing authentic generated product/CMS/image bytes cannot be replaced by repository source or an old digest. A CSS Git inverse is not complete rollback. |
| HOMECOMING owner release approval | Concrete source/overlay/payload/rollback identities, concurrency state, tested route, bounded live acceptance and rollback triggers | Main integration, deployment and served-site changes remain prohibited until that specific release is approved. |

Provider recovery and an egress decision precede consideration of live compatibility. Public NIGHTFALL compatibility and privileged COMMAND compatibility have distinct authority and evidence; neither grants the other. Image infrastructure, complete payload/rollback and owner release acceptance are additional gates, not a single consecutive one-day programme.
