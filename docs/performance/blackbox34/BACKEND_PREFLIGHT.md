## What this can and cannot establish

A successful future run would establish sampled response compatibility and effective public readability for those projections. It cannot independently prove current grants, RLS policy completeness, `security_invoker`, hidden-row exclusion or database ownership. Those structural facts require separately authorised read-only evidence. The historical SQL source is not proof of current deployment. No migration was executed, prepared anew or assumed necessary here.

Only one request selects image identities. Its elapsed time is observable round-trip time, not the database's image-hashing execution cost. Actual query cost and billing attribution remain unverified; do not introduce polling to estimate them.
