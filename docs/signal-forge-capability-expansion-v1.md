## Treble-bleed root cause and composition

The instrument-to-Generator adapter formerly returned null whenever volume controls had different `bleed` values. Choosing a neck-only or bridge-only network therefore disabled wiring, response and kit together. A second normalization rule prohibited 50s plus bleed; the UI cleared bleeds or reset wiring when changing these choices. These were classification/product restrictions, not missing passive network graphs.

`volumeBleeds` maps independent neck and bridge networks onto the existing LP/SG factory. Each capacitor connects volume input lug 3 to wiper lug 2. A parallel resistor connects the same two nodes. Uniform selections also populate the legacy `bleed` field. Independent choices survive inverse adapters, projects, share and both tool interfaces. Response derives the selected channel's actual passive components. Conductive traversal contracts only external wires and closed contacts; capacitors, resistors, winding elements and pot resistance never become ideal edges.

`networks/treble-bleed.mjs` holds the existing authoritative electrical definitions: PRS 180 pF capacitor, capacitor-only 1 nF, Duncan parallel 1 nF + 150 kΩ. Both graph factories consume it. Existing commercial premium/overkill variants continue through the existing Kit Definition electrical mapping; brand/grade/metadata stay in the commercial definition. Marketing labels do not establish new values or switching behaviour. Modern/50s/60s plus these networks are wiring-supported; response remains Modern-only and the commercial 50s kit boundary remains intact.
